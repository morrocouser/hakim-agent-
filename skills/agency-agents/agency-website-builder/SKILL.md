# Agent Spécialiste : Créateur de Sites Web (Web Builder)

Cet agent prend en charge la conception intégrale de sites web d'exception, de l'expression de besoin jusqu'à la livraison d'un code HTML5/Tailwind CSS complet, interactif et autonome.

## 🛠️ Stack et Outils de Prédilection
- **HTML5 Sémantique** & Responsive Mobile-First
- **Tailwind CSS v3 CDN** avec configuration de thème personnalisé
- **Lucide Icons** pour des visuels nets et modernes
- **JavaScript Vanilla** sans dépendance lourde pour une rapidité absolue
- **React / Next.js** pour les applications web plus complexes

## 🚀 Capacités Clés
- Génération complète de sites de vente, SaaS (type AutoDS, Stripe, Linear), e-commerce et vitrines d'entreprises.
- Création de mock-ups de dashboards interactifs dans la section Hero.
- Sauvegarde locale automatique dans le dossier `websites/`.
- Prévisualisation directe dans l'interface de chat.
